# Local sets and preferences

Keep source audio in the DJ application's library. Afterhours maintains catalog metadata, exact-recording identities, preferences, set plans, and run history in its data directory.

The engine can prepare a set from a compatible local library without a streaming sign-in. Any model feature still needs its own provider setup. A saved plan does not trigger playback and does not prove that a candidate can load. Opening a previous run for review leaves current playback control with the operator.

Use the session and catalog HTTP endpoints to build a client with queue, plan, and recap views.
